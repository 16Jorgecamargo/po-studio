# Segurança

O PO Studio roda inteiramente na máquina de quem usa: o app de computador não acessa a rede e o site faz os cálculos no navegador, sem enviar dados para servidor.

## Versões com suporte

Correções de segurança saem na versão mais recente publicada em [Releases](https://github.com/16Jorgecamargo/po-studio/releases).

## Como relatar uma vulnerabilidade

Não abra uma issue pública. Use o [relato privado de vulnerabilidade do GitHub](https://github.com/16Jorgecamargo/po-studio/security/advisories/new) e descreva:

- o que acontece e qual o impacto;
- como reproduzir (arquivo de problema, versão, sistema);
- se possível, uma sugestão de correção.

Você recebe uma resposta assim que o relato for analisado. Depois da correção, o relato pode ser publicado com o devido crédito, se você quiser.
